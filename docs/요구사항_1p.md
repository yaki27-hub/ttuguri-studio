원본: 붙여넣은 요구사항 문서, 약 50줄 → 1페이지 · 화면 4개

## 📌 한 줄 요약
메모 한 줄로 인스타툰을 만들고 성과까지 보게 해 준다

## 🗂 화면별 요구사항
### 1. 작업 · 소재함 — 메모 넣고 만들 방식 고르기
- 메모 입력·원문 보관·노션 저장 (화면 1)
- 형식·내보내기 칩, AI 분류 1·2순위 (화면 1)
- [시안 만들기] → 다음 화면: 문서에 없음 (화면 1)
### 2. 에피소드 작업실 — 메모에서 게시까지 만들기
- 단계 탭: 메모·콘티·이미지·게시 (화면 2)
- 인스타 미리보기·글자 얹기·캡션 검사 (화면 2)
- [문구 복사]·[ZIP] · 다음 화면: 문서에 없음 (화면 2)
### 3. 성과 — 올린 뒤 결과 확인
- 조회·도달·좋아요·댓글·공유·저장 (화면 3)
- 강조 지표: 평균 대비 배수·공유 (화면 3)
- 버튼·다음 화면: 문서에 없음
### 4. 설정 — 제작 기준 직접 고치기
- 캐릭터·말투·금지사항·레퍼런스 (화면 4)
- 계정 아이디·분류 기준·연결 상태·백업 (화면 4)
- 버튼·다음 화면: 문서에 없음

## 🎨 공통 규칙
- 보라 포인트·둥근 카드·굵은 제목 (공통 규칙)
- 넓은 화면은 왼쪽 사이드 메뉴 (공통 규칙)
- 이미지 4:5, 글자는 그림과 따로 (공통 규칙)
- AI는 제안만, [적용]해야 반영 (공통 규칙)
- 색상 코드·글꼴 크기·간격: 문서에 없음

## ⚠️ 확인 필요
- PR 기능 배치 미정 (확인 필요, 가정: 빠른 시안은 메모 단계)
- 화면 간 이동 경로 없음 (화면 1~4, 가정: 1 → 2)
- 빈 화면·에러·로딩 정의 없음 (확인 필요, 가정: 안내 문구 + 다시 시도)
- 제목 간판체 웹 불가 (확인 필요, 가정: Black Han Sans)
- 예약 게시 불가 (확인 필요, 가정: 게시 완료 수동 표시)
- 기기 간 저장 불가 (확인 필요, 가정: 백업 ZIP 안내)
- 외 2건

# 예제 3편 — 콘티 생성 프롬프트 적용 결과

각 편은 **장면 설명**(그림 작업 옆에 붙이기)과 **화면 문구**(말풍선·자막 레이어에 붙이기)를 따로 적었어요.
[각색]은 원문에 없던 것을 덧붙인 부분이에요.

---

## 1편. 요청이 커지는 회사 썰

> 메모: 현업은 이미지만 바꿔달랬는데 PL은 이 페이지 싹 바꿔달래. 나는 옆에서 응? 했음.

**제목** 이미지만 바꿔달랬는데
**추천 형식** 4컷 — 요청 → 전달 → 반응 → 결과로 흐름이 또렷하고, 마지막 반전을 그림으로 보여주기 좋아요.
**첫 화면 문구** 분명 이미지 한 장이었는데…

### 장면 설명

**컷 1**
- 장면: 사무실 책상, 모니터에 웹페이지 시안이 떠 있음.
- 인물: [왼쪽] 현업 담당자(실루엣) — 모니터 속 배너 이미지 하나를 손가락으로 콕 가리킴 / [오른쪽] 뚜구리 — 고개 끄덕, 여유로운 표정
- 핵심 연출: 손가락 끝이 '이미지 한 장'에만 닿아 있을 것

**컷 2**
- 장면: 같은 자리, PL이 뚜구리 옆으로 옴.
- 인물: [왼쪽] PL(실루엣) — 손바닥으로 화면 전체를 크게 쓸어내리는 제스처 / [오른쪽] 뚜구리 — 아직 상황 파악 전, 무표정
- 핵심 연출: 컷 1의 '손가락 한 점' ↔ 컷 2의 '손바닥 전체' 대비

**컷 3**
- 장면: 배경 생략, 뚜구리 얼굴 클로즈업.
- 인물: [가운데] 뚜구리 — 눈 동그랗게, 입 살짝 벌림, 머리 위 물음표
- 핵심 연출: 정지된 듯한 멍한 표정

**컷 4** (무언)
- 장면: 피그마 화면 전체. 파란 선택 테두리가 이미지 한 장 → 페이지 프레임 전체로 커져 있음. [각색]
- 인물: [오른쪽 아래] 뚜구리 — 화면 구석에 작게, 마우스 쥔 채 굳어 있음
- 핵심 연출: 선택 테두리의 크기 변화 (흐릿한 작은 테두리 잔상 + 큰 테두리)

### 화면 문구

| 컷 | 대사 | 자막·속마음 |
|---|---|---|
| 1 | 현업: "여기 이미지만 바꿔주세요." | — |
| 2 | PL: "이 페이지 싹 바꿔주세요." | — |
| 3 | 뚜구리: "응?" | — |
| 4 | 글자 없음 — 그림으로만 | — |

### 이미지 제작 메모
- 비율: 4:5, 4컷은 2×2 또는 세로 4단
- 컷 1·2는 같은 카메라 앵글로 그려야 대비가 살아요
- 컷 4 피그마 UI는 실제 화면 캡처 대신 단순화한 선 그림으로 (레이어 패널·툴바 정도만)
- 화면 속 글자: 넣지 않고 피그마 텍스트 레이어로

### 각색 표시
- 컷 1·2 대사 문장은 원문 요약을 말로 옮긴 것 (내용은 원문 그대로)
- 컷 4 피그마 선택 테두리는 시각적 장치 [각색]

## 2편. 운동복만 출근함

> 메모: 퇴근하고 운동하려고 운동복까지 챙겨 갔는데 그냥 집에 옴. 운동복 가방 든 채로 소파에 누웠어.

**제목** 운동복 출퇴근
**추천 형식** 한컷 밈 — 한 장면으로 웃음이 끝나는 이야기예요.
**첫 화면 문구 (그림 안 자막)** 운동복, 오늘도 출퇴근 완료.

### 장면 설명

**한컷**
- 장면: 저녁, 거실 소파. 조명은 스탠드 하나만 켜진 어스름한 톤.
- 인물: [가운데] 뚜구리 — 출근복 그대로 소파에 엎어지듯 누움, 눈 감고 녹아내린 표정. 한 손은 운동 가방 손잡이를 꼭 쥔 채 바닥으로 늘어뜨림
- 소품: 지퍼가 꽉 닫힌 운동 가방 [각색: '안 열었다'는 표시]
- 핵심 연출: 가방은 멀쩡히 꽉 찬 채, 사람만 녹아 있는 대비

### 화면 문구

| 컷 | 대사 | 자막 |
|---|---|---|
| 한컷 | 글자 없음 — 그림으로만 | 운동복, 오늘도 출퇴근 완료. |

### 이미지 제작 메모
- 비율: 4:5 (1:1로 올릴 거면 소파를 가로로 길게)
- 구도: 살짝 위에서 내려다보는 앵글, 소파와 가방이 한 화면에
- 자막 위치: 상단 여백 또는 하단 바닥 쪽
- 화면 속 글자: 자막만 피그마에서 올리기

### 각색 표시
- 가방 지퍼를 '꽉 닫힌' 상태로 강조한 것 (원문 "그냥 집에 옴"에서 추론)

## 3편. 사무실 립밤 정착기

> 메모: 가을 겨울에 큰 사무실이 너무 건조해. 친구들이랑 립밤 얘기하다가 깨달았는데 난 약국에서 산 프로캄 판테놀 립에센스만 계속 씀. 진짜 생활템이야.

**제목** 사무실 립밤 정착기
**추천 형식** 컷자막형 3장 — 잔잔한 생활템 이야기라 자막으로 읽히는 게 어울려요. 피그마에서 같은 프레임을 3장 복제해 쓰면 돼요.
**첫 화면 문구** 가을만 되면 사무실이 사막

### 장면 설명

**1장**
- 장면: 천장이 높은 넓은 사무실, 히터 바람이 흐르는 선. 창밖은 낙엽.
- 인물: [가운데] 뚜구리 — 자리에 앉아 손가락으로 입술을 만짐, 입술에 작은 갈라짐 표시
- 핵심 연출: 사무실은 크고 뚜구리는 작게 — 건조함이 공간 전체에 퍼진 느낌

**2장**
- 장면: 친구들과 대화하는 장면. 원문에 장소가 없으니 배경은 단순하게 (단톡방 말풍선이나 빈 배경)
- 인물: [왼쪽·오른쪽] 친구들(실루엣) — 각자 다른 립밤을 들어 보임 [각색] / [가운데] 뚜구리 — 듣다가 '아' 하고 깨닫는 표정
- 핵심 연출: 친구들 립밤은 여러 개, 뚜구리는 깨달음 표시(전구·느낌표)

**3장**
- 장면: 뚜구리 책상 위 파우치.
- 인물: [가운데] 뚜구리 — 파우치에서 프로캄 판테놀 립에센스를 꺼내 들고, 담담하게 웃음
- 핵심 연출: 제품이 또렷이 보이게, 과장 없이 '늘 쓰던 것'을 꺼내는 손짓

### 화면 문구

| 장 | 대사 | 자막 |
|---|---|---|
| 1장 | 글자 없음 — 그림으로만 | 가을·겨울, 큰 사무실은 너무 건조하다. |
| 2장 | 친구: "너 립밤 뭐 써?" [각색] | 친구들이랑 립밤 얘기하다가 깨달았다. |
| 3장 | 글자 없음 — 그림으로만 | 난 결국 약국에서 산 이것만 계속 쓰고 있었다. 프로캄 판테놀 립에센스, 진짜 생활템. |

### 이미지 제작 메모
- 비율: 4:5, 세 장 모두 같은 프레임 (자막 영역 위치 고정)
- 자막 영역: 하단 1/4 고정 박스 → 피그마에서 프레임 복제 후 글자만 교체
- 3장 제품: 실제 패키지 사진을 참고해 단순화해서 그리기
- 협찬이 아니면 '광고' 표기는 필요 없음. 받은 제품이면 첫 장에 표기

### 각색 표시
- 2장 친구 대사 "너 립밤 뭐 써?" (원문은 '립밤 얘기'까지만)
- 2장 친구들이 각자 립밤을 들어 보이는 장면
- 1장 창밖 낙엽·히터 바람선은 계절·건조함을 보여주는 배경 장치

# 뚜구리 스튜디오

@ttuguri 인스타그램 게시물 성과를 모아 보고, 노션 **🎬 에피소드 DB**에 자동으로 기록하는 대시보드입니다.

- 게시물별 조회 · 도달 · 좋아요 · 댓글 · 공유 · 저장 · 공유율 · 저장률
- 게시물 ↔ 노션 에피소드 연결 (드롭다운에서 고르면 Media ID, 링크, 업로드일, 성과가 바로 기록됨)
- 매일 오전 9시(KST) 자동 동기화 + "지금 노션에 동기화" 버튼
- 토큰 만료 14일 전부터 화면에 알림

**제작 탭 (/studio, 모바일 우선)**
1. 소재 메모 → 노션에 `아이디어` 상태로 저장
2. 소재 추천 → 내 메모 · 성과 · 시기를 섞어 AI가 3개 추천, 고르면 `스토리`로 저장
3. 콘티 생성 → AI 초안을 고쳐서 노션 본문 끝에 추가 (기존 본문은 지우지 않음), 상태 `콘티`
4. 단계 넘기기 → 이미지 제작 → 검수 → 업로드 완료

**작업실 (/studio/work)**: 메모 한 번으로 소재 → 이야기 → 콘티 → 이미지 → 게시 패키지까지
- 원문은 그대로 두고 정리 · 사실은 확인/추정/모름으로 구분
- 컷별 직접 편집 · 잠금 · 이전 버전 · 이 컷만 수정 · 순서 변경(이미지 연결 유지)
- 초안은 **AI로 받기**(서버 키가 있을 때) 또는 **프롬프트 복사 → 결과 붙여넣기**, 항상 적용 전 미리보기
- 컷별 이미지 첨부 → 슬라이드 구성 → 게시 패키지 ZIP(이미지·caption.txt·alt-text.txt·storyboard.md)
- 게시 완료는 직접 올린 뒤 수동 표시, 반응 기록은 확인한 값만(미확인은 빈칸)
- 데이터는 **이 브라우저(IndexedDB)** 에만 저장됨 → 설정 화면에서 백업 ZIP 내려받기/가져오기
- 노션 에피소드 화면의 “작업실에서 이어서 만들기”로 연결

**설정 (/studio/settings)**: 캐릭터·말투·금지사항·그림체·레퍼런스 이미지 편집, AI 지시문 미리보기, 연결 상태(키 값은 표시 안 함), 백업

## 처음 설정 (한 번만)

### 1. 노션 통합 만들기
1. https://www.notion.so/profile/integrations → **새 통합** → 이름 `뚜구리 스튜디오`, 유형 **내부** → 저장
2. **내부 통합 시크릿**을 복사 → Vercel 환경변수 `NOTION_TOKEN`에 넣을 값
3. 노션에서 **🎬 에피소드 DB** 페이지 열기 → 오른쪽 위 `•••` → **연결** → `뚜구리 스튜디오` 추가

### 2. Vercel 환경변수
Vercel 프로젝트 → Settings → Environment Variables 에 `.env.example`의 항목을 모두 넣습니다.

| 이름 | 값 |
|---|---|
| `IG_ACCESS_TOKEN` | 연장한 60일 토큰 |
| `IG_USER_ID` | `17841449312506270` |
| `TOKEN_EXPIRES_AT` | `2026-12-30` |
| `SINCE_DATE` | `2026-10-24` |
| `NOTION_TOKEN` | 1번에서 복사한 시크릿 |
| `NOTION_DATA_SOURCE_ID` | `e4f6717a-4610-4a08-86cf-b555b363e582` |
| `DASHBOARD_PASSWORD` | 접속 비밀번호 (직접 정하기) |
| `CRON_SECRET` | 아무 긴 문자열 |
| `GEMINI_API_KEY` | Google AI Studio 에서 발급한 키 |
| `AI_PROVIDER` | (선택) `gemini`(기본) 또는 `claude` |
| `GEMINI_MODEL` | (선택) 비우면 사용 가능한 최신 flash 모델 자동 선택 |
| `ANTHROPIC_API_KEY` / `CLAUDE_MODEL` | (선택) Claude 로 바꿀 때 |

환경변수를 바꾼 뒤에는 **Deployments → 최신 배포 → Redeploy** 를 해야 적용됩니다.

## 토큰 갱신 (60일마다)
1. https://developers.facebook.com/tools/debug/accesstoken/ 에 현재 토큰 붙여넣기 → 디버그 → **액세스 토큰 확장**
2. 새 토큰으로 `IG_ACCESS_TOKEN` 교체, `TOKEN_EXPIRES_AT` 을 새 만료일로 수정 → Redeploy

## AI 지시문
캐릭터·제작 규칙은 **설정 화면**에서 고칩니다. 제작 탭(소재 추천·콘티)과 작업실 모두 그 설정으로 지시문을 만듭니다.
설정을 불러오지 못한 경우에만 `lib/studio.js` 의 `SYSTEM` 이 기본값으로 쓰입니다.
